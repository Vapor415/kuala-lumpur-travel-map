# 吉隆坡旅行地图 · 四天三晚

打开 `index.html` 即可使用。需要联网加载 Leaflet 1.9.4、MarkerCluster 1.5.3、MapLibre GL JS 5.6.2、Leaflet 适配器 0.1.3 和 OpenFreeMap 矢量底图；不需要 API Key、安装依赖或构建。浏览器需支持 WebGL。

网页文件已集中在 `D:\code\tourPlan\web-map`。在这个目录执行 `node server.cjs`，打开 http://localhost:8080。

## GitHub Pages 发布

此子目录是独立的网站仓库。预览图位于 `previews/` 并由 `.gitignore` 排除；项目根目录的 Word、PDF 和手写材料不提交到网站仓库。

网站使用相对资源路径，支持 GitHub Pages 仓库子路径。根目录的 `.nojekyll` 用于直接发布 HTML、CSS、JavaScript 与 GeoJSON，不需要构建。

首次发布：安装有 Node.js 和 Git 时，在这个目录执行 `./publish.ps1`（或 `node publish.cjs`）。脚本通过 GitHub CLI 的公开 OAuth 应用发起设备登录，只申请公开仓库权限。打开脚本给出的 GitHub 登录地址，输入一次性代码并授权；随后默认创建公开仓库 `kuala-lumpur-travel-map`，配置 GitHub Pages 的 `main` 分支根目录来源，并输出公开网址。

登录信息及部署记录仅保存在被 Git 忽略的 `.publish/` 内，不提交到仓库。可用 `./publish.ps1 -Login` 重新登录，或通过 `GH_TOKEN` 环境变量提供已有授权。

后续更新网页或地点数据后，可再次运行发布脚本提交并推送。页面更新可能需要几分钟；发布后无需运行本地 Node 服务。底图和地图依赖仍需要访问公网服务。

## 功能与接入

- 动态缩放底图、米/公里比例尺、聚合点位、点击详情、重叠点展开。
- 日期、地区、类型、关键词联合筛选，备选地点开关。
- 住宿仅保留 Royce Residence KLCC；日期筛选显示时间轴、每站活动与停留时长，以及站间交通方式和预计耗时。重复编号表示返程或再次经过同一地点。
- 地图箭头表示前进方向；点击时间轴站点或通勤段可定位并突出当前路段，顶部时间轴的上一阶段／下一阶段按钮可按顺序浏览。相同地点的不同停留分别展示；共享游览时段和演唱会去程总通勤不重复累加。原计划未给出的短途耗时标为建议或估算，非实时导航。
- 每日甘特式时间轴只位于地图列上方，左侧栏目占据完整高度。顶部只展示区域游览、休息及主要通勤，合并同一区域的小景点与短途步行；演唱会去程的候车、换乘和步行合并计时。分段最小宽度 170px、间距 12px，可横向滚动，条宽非严格时间比例。点击阶段及上一阶段／下一阶段可同步地图与详细列表。
- 地图、详情、路线与 GeoJSON 均移除餐饮点位，行程展示不包含餐饮安排；阳光广场仅保留伴手礼采购用途。
- 11/3–6 四天三晚：抵达与 KLCC 夜景；上午老城、下午布城；水族馆、午休与演唱会；休息退房与返程。顺序列表及点位弹窗显示新版时间段，其他筛选保留原编号，隐藏站点前后的路线不跨站连接。
- 路线为行程顺序示意，并非道路导航；11/6 可按机票切换返程 T1/T2。Grab 直达路线中的铁路站点作为备选交通显示，返程日不新增景点。
- 市区视图、旅行全域、当前筛选结果的 GeoJSON 导出。
- `places.js` 是独立地点数据；`styles.css` 是界面样式；`map.js` 是地图逻辑。
- `basemap-style.js` 为简洁底图样式：隐藏地铁/铁路、站名、道路编号、建筑、其他底图 POI、行政边界及土地用途色块；水域和绿地淡化，补充主干道路、大型河湖与主要公园名称；小街道/支路/步行道仅在 Leaflet 缩放第 16 级及以上显示。城市地名仅保留少量主要文字。
- `travel-places.geojson` 是全量点位，可直接接入其他地图引擎。GeoJSON 使用 WGS84，坐标顺序为经度、纬度。
- `window.TRIP_MAP` 暴露地图实例、地点和 marker，可供后续展示界面调用。
- 合并标注按“旅行全域 → 城市区域 → 子区域 → 地点”树结构的共同父节点命名，例如酒店区域、老城区域、演唱会区域。普通点和日期路线点共用聚合逻辑，路线编号在放大或展开后显示。
- 右下角标注图例随缩放、平移、筛选及聚合展开更新，只列出当前视野内实际显示的标注。展开条目可查看区域树及地点，点击地点可定位并打开详情；数字在合并标注上表示地点数量，在路线地点上表示游览顺序。
- 底图补充主干道路名称、大型河湖名称及主要公园名称，保留淡色水域和绿地。小街道、道路编号、其他底图 POI、铁路站名、建筑与行政边界仍按简洁样式设置。

## 数据范围

来源为项目中的《吉隆坡4天3晚行程计划.docx》，仅保留新版安排涉及的具体地点，移除马六甲、云顶及旧版补充景点；住宿精简为一个 KLCC 选项。别名合并（布特拉广场/太子广场等）；共址店铺独立保留。每日顺序与休息时间按新版行程展示。营业时间、票务及交通需结合实际出行确认。

所有坐标为行程展示级概略定位，未逐点核验实际入口。街道与湖区采用代表点。地图详情提供按名称搜索的链接，出行前需确认入口。演唱会日期按新版计划展示，不作为官方活动时间核验。

餐饮服务点位与餐饮安排已按展示要求移除。南京、西安及昆明为返程或中转参考，不放入当地底图。住宿为 11/3 入住、11/6 退房，共 3 晚。
